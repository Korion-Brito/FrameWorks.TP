# Frameworks.TP

## 📖 Sobre o Projeto

Projeto Full Stack desenvolvido com o objetivo de aplicar conceitos modernos de desenvolvimento web, integração entre front-end e back-end, persistência de dados e hospedagem de aplicações.

A aplicação foi construída utilizando Angular no front-end, Node.js no back-end e MongoDB como banco de dados, permitindo a comunicação entre as camadas através de APIs.

Este projeto foi desenvolvido durante minha formação acadêmica para consolidar conhecimentos em desenvolvimento web e arquitetura de aplicações.

---

## 🎯 Objetivos

- Desenvolver uma aplicação Full Stack funcional;
- Aplicar conceitos de Front-end e Back-end;
- Trabalhar com banco de dados NoSQL;
- Desenvolver e consumir APIs;
- Praticar integração entre diferentes tecnologias;
- Aprimorar conhecimentos em arquitetura de aplicações web.

## 🏗️ Arquitetura do Projeto

O projeto segue uma estrutura Full Stack dividida em:

### Front-end
Responsável pela interface do usuário e interação com a aplicação.

### Back-end
Responsável pelas regras de negócio, processamento de dados e comunicação com o banco de dados.

### Banco de Dados
Responsável pelo armazenamento e recuperação das informações da aplicação.

## 🚀 Como Executar o Projeto

### 1. Clonar o repositório

```bash
git clone https://github.com/Korion-Brito/FrameWorks.TP.git
```

### 2. Instalar dependências do Front-end

```bash
npm install
```

### 3. Executar aplicação Angular

```bash
ng serve
```

### 4. Executar o Back-end

```bash
npm start
```
